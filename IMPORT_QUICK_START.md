# 🚀 Quick Start: Import Open Source Content

## One Command to Rule Them All

```bash
cd backend
node scripts/importOpenSourceContent.js
```

## What Gets Imported

✅ **6 New Lessons** from 4 sources:

1. **Algebra** (Khan Academy)
2. **Cell Biology** (OpenStax)
3. **Algorithms** (MIT)

## Search These Tags

After import, try searching:
- `algebra` - Math lesson
- `biology` or `cells` - Science lesson
- `algorithms` - Computer science
- `photosynthesis` - Biology
- `solar` - Astronomy
- `war` or `history` - History
